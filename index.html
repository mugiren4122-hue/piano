Standard MIDI File → Note Sequence

MIDI→JSON コンバーター

MIDIファイル（.mid / .midi）を読み込み、{ key, delay } 形式の ノートシーケンスJSONに変換します。すべての処理はブラウザ内で行われ、 ファイルはどこにも送信されません。

01 / ファイルを読み込む

クリックまたはドラッグ&ドロップ
.mid / .midi

02 / 結果

変換するとここにノートロールが表示されます
ファイルを選んで「変換する」を押してください。

03 / 仕組み

MIDIファイルをバイナリレベルで解析し、ノートオン・テンポ変更イベントを抽出します。 同時に鳴るノートは和音として束ね、設定した間隔より短い間隔のノートは間引かれます。 最終的に各ノートは { key: "Key2C", delay: 0.34 } のように、 鍵盤名と直前のノートからの経過秒数（delay）の配列として出力されます。

対応する音域は MIDIノート番号 60〜84（C4〜C6、2オクターブ）です。
